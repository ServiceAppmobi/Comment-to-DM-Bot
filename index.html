Jak uruchomić projekt na GitHubie w 3 minuty

          
Projekt nie wymaga żadnego konta Facebook Developers, żadnych kluczy API ani nawet instalacji npm.


          

            

              
Krok 1: Wypchnij repozytorium na GitHub

              
Utwórz nowe repozytorium na GitHubie i wrzuć pliki z folderu projektu (git push lub przez przeglądarkę).

            

            

              
Krok 2: Włącz GitHub Pages

              
W repozytorium wejdź w Settings → Pages → Source: GitHub Actions. Workflow deploy-pages.yml automatycznie opublikuje ten panel oraz stronę /whatsapp.html.

            

            

              
Krok 3: Wpisz swój numer WhatsApp w data/rules.json

              
Skonfiguruj numer i reguły w zakładce Click-to-WhatsApp Studio, kliknij Pobierz rules.json i podmień plik data/rules.json w repozytorium.

            

            

              
Krok 4: Prawdziwy Bot komentarzy w GitHub Actions (gratis!)

              
Workflow github-comment-bot.yml działa automatycznie w zakładce Issues Twojego repozytorium. Gdy ktoś napisze komentarz ze słowem np. CENNIK lub WHATSAPP, bot sam odpowie i wygeneruje spersonalizowany link Click-to-WhatsApp (używa wbudowanego GITHUB_TOKEN).

            

          

        


        

          
Co działa realnie bez integracji z Facebookiem?

          
Uczciwy podział możliwości technicznych:


          

            

              
✅ Click-to-WhatsApp (100% produkcyjne)

              
Linki https://wa.me/48..., kody QR, strona whatsapp.html (Link-in-Bio) i pływający widget HTML działają od razu z każdym numerem WhatsApp — zero rejestracji w Meta Developers.

            

            

              
✅ Bot komentarzy na GitHubie (100% produkcyjne)

              
GitHub Actions (scripts/github-bot.mjs) automatycznie skanuje komentarze pod Issues/PR, dopasowuje reguły z data/rules.json i publikuje odpowiedzi z przyciskiem WhatsApp.

            

            

              
✅ Symulator Comment-to-DM & CRM Leadów

              
Pozwala zaprojektować, przetestować i pokazać klientowi cały lejek Instagram/FB Comment-to-DM + eksport leadów CSV/Webhook bez dostępu do konta Meta.

            

            

              
ℹ️ Wysyłanie prawdziwych DM na Instagramie/FB

              
Meta blokuje wysyłanie prywatnych wiadomości bez tokenu aplikacji Meta — dlatego ten projekt daje Ci działający zamiennik (Click-to-WhatsApp + Link-in-Bio + GitHub Bot + gotowy silnik reguł src/engine.js, który kiedyś możesz łatwo podpiąć pod API).
